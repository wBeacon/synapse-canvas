# WorkBuddy 常驻 UI 接入咨询稿

主题：咨询普通客户端账号的第三方常驻 UI 接入方式

你好，我们正在开发开源项目 [Synapse Canvas](https://github.com/wBeacon/synapse-canvas)，希望为 WorkBuddy 提供可视化会话地图。项目基于 dsh-synapse 衍生，已获得原作者支持并保留来源和 MIT 许可声明。

目前已在 macOS WorkBuddy 5.9.2 企业版客户端验证对话内 MCP App，但账号只有普通客户端使用权限，没有企业管理或 Buddy 应用配置权限。我们的目标是让用户从固定入口打开画布，独立于某条工具消息使用，并在切换任务后保留视图。

想请教以下问题：

1. 普通用户能否安装带独立导航入口的第三方 UI？如支持，官方 SDK、插件规范、最小示例和本地调试入口在哪里？
2. Buddy 应用的网页资源包菜单是否适合此场景？需要什么开发者主体、资质或灰度权限，能否先在自己的客户端进行预览测试？
3. 是否有对第三方开放的 `.wbext` UI Extension 路径？如果有，签名与分发如何申请？
4. 自定义页面切换任务、关闭窗口和重启后的保活 / 恢复行为有何契约？
5. 是否有公开 API 让该页面读取经用户选择授权的本地开发任务历史？我们会将此权限与页面安装分开验证。

我们已准备不含真实历史的最小静态网页包，可按官方流程提供验证。感谢指引。
